# Audyty poprzednich PR-ów (`docs/audits/`)

W tym katalogu zapisujemy pełne raporty audytu poprzednich scalonych PR-ów (krok 3 w [`AGENTS.md`](../../AGENTS.md)), ilekroć audyt wykryje usterki merytoryczne, kodowe lub porządkowe wymagające szerszego udokumentowania niż krótka wzmianka w opisie bieżącego PR-a.

## Nazewnictwo

```text
RRRR-MM-DD-pr-<numer>.md
```

Każdy raport rozbija wnioski na trzy części: **(3a) Merytoryczny**, **(3b) Kodu i testów**, **(3c) Pozostałych zmian**, wraz ze wskazaniem commitów naprawczych lub propozycji decyzji dla właściciela.
