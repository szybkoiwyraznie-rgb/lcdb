# Audyty poprzednich sesji (`docs/audits/`)

Katalog przechowuje raporty z obowiązkowego trójczęściowego audytu poprzedniego scalonego PR-a (`3a` merytoryczny, `3b` kodu i bram, `3c` pozostałych zmian), wykonywanego na starcie każdej kolejnej sesji zgodnie z [`AGENTS.md`](../../AGENTS.md) §2 i [ADR 0014](../decisions/0014-sesja-galaz-pr-i-audyt.md).

Konwencja nazewnictwa: `pr-<numer>.md` (np. `pr-2.md`).
