# Rejestr decyzji architektonicznych (`docs/decisions/`)

Każda istotna decyzja dotycząca architektury technicznej, modelu danych, reguł redakcyjnych lub organizacji pracy w repozytorium `lcdb` otrzymuje własny rekord ADR o ciągłej czterocyfrowej numeracji. Zestaw startowy przenosi sprawdzone rozstrzygnięcia z repozytoriów `wwm` i `srw`, dostosowane od pierwszego dnia do specyfiki opowieści *Limbus Company*.
