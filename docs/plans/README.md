# Plany prac wieloetapowych (`docs/plans/`)

Katalog przeznaczony na plany większych rozbudów silnika, migracji schematu lub przekrojowych porządków obejmujących więcej niż jedną sesję. Zwykły plan pojedynczej sesji mieszczący się w opisie PR-a (krok 4 w [`AGENTS.md`](../../AGENTS.md)) nie wymaga osobnego pliku tutaj.
